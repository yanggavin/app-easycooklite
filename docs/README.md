# Public support site

Deploy this folder's contents as the document root for `cook-chinese-app.newtree.tech`. No build step, JavaScript, external fonts, analytics or backend is required.

- `/index.html`: technical support
- `/privacy.html`: privacy policy
- `/terms.html`: terms and attribution, referencing Apple's Standard EULA

Set DNS for the hostname, configure HTTPS, and redirect HTTP to HTTPS. The hostname did not resolve during the October 11 audit. Hosting and email delivery have not been configured by this repository.

The app uses the supplied HTTP URLs until HTTPS is verified; switch to HTTPS once the certificate and pages are live. Check all pages without authentication, mobile layouts, and receipt of mail at `support@cook-chinese-app.newtree.tech` before submission.

Local HTML parsing and relative link/asset checks passed. Browser visual preview was unavailable, so verify the responsive pages on the deployed host before submission. Terms references Apple's authoritative Standard EULA and does not introduce a custom license; review the app-specific legal/privacy text before publication.
